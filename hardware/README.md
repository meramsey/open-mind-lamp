# Hardware

The supported design and primary-source links are in [docs/hardware.md](../docs/hardware.md).
No manufacturer schematic/demo has been copied or relicensed here. Confirm the
actual PCB revision before flashing. Pin assignments are specific to Waveshare
ESP32-S3-Matrix and are not a generic ESP32-S3 preset.

Suggested bill of materials: matrix board, USB data cable, regulated 5 V USB
supply with headroom, and optional ventilated frosted diffuser. No soldering,
external server, or sensor is needed for the default lamp.
